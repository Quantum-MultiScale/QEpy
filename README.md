# QEpy — Quantum ESPRESSO in Python

**QEpy** turns [Quantum ESPRESSO](https://www.quantum-espresso.org/) into a programmable Python DFT engine: external potentials, custom XC, iterative SCF, ASE integration, and more.

**Documentation:** [qepy.rutgers.edu](https://qepy.rutgers.edu/)

## Quick install

Serial build from PyPI (see the [install guide](https://qepy.rutgers.edu/install.html) for MPI, source builds, and platform notes):

```shell
python -m pip install qepy
```
